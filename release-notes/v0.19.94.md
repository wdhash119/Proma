# Proma v0.19.94 更新

本次为质量与安全加固版本，集中修复一轮源码审查发现的自操作边界、数据保护与若干功能缺陷，无新增功能。

## 安全与数据保护

- **自操作安全边界收紧** — Agent 无法再代填或代发你的聊天/Agent 输入区，也无法代答 AskUserQuestion 提问；新建项目必须先获得你的明确批准，「不同意」「拒绝」等否定回答不再被误判为同意。批准后的点击会按目标身份重新定位，界面已变化时安全取消而非误点。
- **Worktree 目录归属修正** — 清除活动 worktree、或把会话迁移到另一工作区后，即使旧 worktree 目录仍在，cwd 也不再被它劫持，避免在错误项目里执行写操作；恢复单个 worktree 不再误注销其他暂时失效但可恢复的 worktree 登记。
- **记忆初始化与写入保护** — MemoryInitialize 不再把超大（>512KiB）、符号链接或读取异常的非空 `MEMORY.md` / `AGENTS.md` 当成空文件覆盖；记忆更新与历史恢复统一受 512KiB 上限与全局画像预算（100 条 / 5000 码元）约束；历史快照 ID 防路径穿越并绑定目标，设置页恢复会拒绝并发覆盖；主题归档在崩溃后可自动续跑，不再留下「索引仍引用、正文已移走」的中间态。
- **旧画像迁移解死锁** — `.claude/memory` 旧布局的迁移 / 续跑 / 重规划不再卡死；来源与归档副本均缺失时不再谎报迁移完成；多文件迁移中途被外部修改时如实报告部分写入并可续跑。

## 体验修复

- **按住说话竞态** — 长按越过阈值后快速松手，不再漏掉点击抑制，避免额外触发普通听写或在旧会话收尾后重复录音。
- **完成提醒统一门控** — 桌面通知与提示音合并为单一入口：仅成功且未查看时提醒一次，失败 / 用户停止不再伪装成「任务完成」；定时任务的「仅失败提醒 / 完全安静」策略现在同样作用于桌面通知与声音（失败提醒仍由外部通知目标按策略承担）。
- **PR 状态与关联** — 经典 CI（StatusContext）失败正确显示「检查失败」、成功计入通过数；`gh pr view/edit/checkout` 输出里的 PR 链接可被识别并关联；旧版单条 PR 绑定在启动时即刷新；异步发现期间切换仓库不再把旧仓库 PR 写入当前会话；后台 PR 状态更新不再自动解归档会话。
- **Markdown 渲染** — 引用式链接与脚注的定义跨段落不再退化成字面量，缩进代码块保留首行缩进语义；流式输出时未变化的历史块不再重复重渲染。
- **Computer Use 版本与预览** — 安装检测与更新检查共用同一版本解析（兼容 `(build …)` 后缀），结论不再互相矛盾；清单协议错误不再被缓存掩盖成「已是最新」；慢速重试期间切换会话不再把旧画面串到新会话。
- **Web 抓取 / 搜索健壮性** — 搜索响应边读边停，2MiB 上限真正约束下载量与内存；已取消的搜索立即中止；`charset="gbk"` 等带引号编码正确解码；非法 Unicode 数值实体不再导致整页或整次检索失败。
- **清单快速捕获回退** — 系统占用全局快捷键时，应用内 Ctrl/Cmd+Shift+T 仍可触发快速捕获；全局注册成功且窗口聚焦时只触发一次，不重复打开。
