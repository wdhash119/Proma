# Proma v0.19.162 更新

## 新增

- **设置「磁盘管理」升级为「数据管理」** — 存储用量、数据清理、数据目录、跨设备迁移整合为一页；原「数据迁移」页整体并入（迁移原理、创建压缩包与恢复提示词原样保留），旧标签页状态自动映射到新页面。
- **数据目录整体迁移** — 支持把整个数据根（`~/.proma`）迁移到自选目录：预检（目标目录合法性、剩余空间、运行中会话）→ 复制 → 逐文件校验 → 写入路径指针 → 重启生效。旧数据默认保留，页面提供「删除旧数据」（二次确认，当前根缺少关键文件时拒绝）与「回滚到旧目录」；迁移同步改写会话索引、工作区索引与 Vault 配置中位于数据根内的绝对路径，迁移后会话续跑与孤儿判定不受影响。
- **过期孤儿数据清理** — 扫描 → 预览 → 确认清理，过期阈值 7/30/90 天可选（默认 30，按最后修改时间）。覆盖无索引引用的会话消息、无引用的 Pi artifact、孤立 spine sidecar、过期会话工作目录、Claude SDK 遗留目录（projects/、file-history/）；会话附件类目因引用关系无法确认只预览不删除。新增「启动时自动清理过期孤儿数据」开关，默认关闭。

## 优化

- **归档会话清理补齐实现** — 超过保留天数的归档会话同时删除消息 JSONL、Pi artifact 与 spine sidecar、会话工作目录（此前只删 JSONL，与页面文案不符）；索引条目保留，运行中会话跳过。
- **孤儿清理安全边界** — 会话工作目录按 UUID 命名 + 索引全量引用判定，memory/ 等非 UUID 目录结构性不会被触碰；清理执行时重扫并与预览路径取交集、删除前逐条重校验引用；破坏性清理接口在类型层面强制显式传入数据根，杜绝回退真实目录。
