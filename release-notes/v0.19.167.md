# Proma v0.19.167 更新

> 累积发布：包含 v0.19.165 之后至 v0.19.167 的全部变动（v0.19.166 / 0.19.167）。

## 新增

- **会话级委派策略** — 模型选择弹窗的「搜索模型」行右端新增「委派」复选框，勾选后弹层向左扩展出委派设置面板，约束本会话发起的协作子 Agent；取消勾选即清除策略、回到默认行为（对委派零影响）。策略属于会话本身：分叉（fork）自动继承，历史会话不受影响，修改于下一轮生效。
  - **两种模式**：「继承」强制子会话使用当前对话的渠道与模型；「指定」固定使用选定的模型——切换时默认选中当前主模型，下拉按渠道分组可改选。委派模型下拉常驻显示：继承模式下为禁用态并回显主模型，指定模式下可切换。
  - **硬约束**：非默认模式下，委派工具的 `channelId`/`modelId` 参数直接从工具 schema 中移除，Agent 无法自行换模型；解析层兜底忽略并在结果中说明。需要一次性跨供应商委派时，临时取消勾选即可。
  - **同时运行上限**：可设 1–50（留空为系统默认 50），语义是同时运行的子会话数量天花板，不强制派满；批量委派按整批数量计入，超出时整批拒绝并给出可读错误。上限从第一轮起就对 Agent 可见（系统提示词、工具说明与批量参数描述同步声明），不再先撞错才知道。
  - **子会话思考强度**：可选七档（关闭～最大）；设置后硬覆盖 Agent 传参，委派子会话固定使用该强度。使用不支持思考的模型（如 deepseek-flash）时建议选「关闭」，规避续跑 400。
  - **失效回落**：指定的模型被禁用或删除时，面板显示警示条，委派自动回落默认模式（尊重 Agent 传参），结果体携带回落原因，不静默换模型烧别家额度。
  - **可见性**：策略生效时模型选择按钮右上角显示小圆点标识；委派子会话中入口禁用并提示「委派子会话不会再继续委派」。自动化表单、视觉中继设置等其他模型选择入口不受影响。

## 修复

- **Live Compact 压缩事件按发生位置插入过程流** — 切割事件此前行渲染时被整批追加在过程组末尾，叠加分组合并后一轮内的多次切割全部堆在整轮结尾，读不出发生在哪一步。现在事件携带顶层块锚点，切割行插回它实际发生的工具行之间（与工具调用同级同缩进），并按最终回答两侧分侧承载；跨轮补发、回挂目标被新用户输入清空的事件独立成行兜底显示，不再静默丢失。
