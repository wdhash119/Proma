# Proma v0.19.161 更新

## 新增

- **选区临时 Agent** — 选区问答从 Chat 切换为右侧普通非 draft Agent；返回已存在的选区 Agent 时，新引用追加到该会话草稿（编辑器尚未挂载时不再覆盖旧引用）；关闭 Tab 不删除会话，再次发起新建。
- **运行状态行实时指标** — 运行指示器新增当前事项（THINKING / TEXT / 工具名）、耗时、缓存命中率与输出速率；分层刷新：事项随消息即时更新、耗时 1s、缓存命中率与输出速率 5s 快照，数字不再随流式增量频繁跳动。
- **Live Compact「显示压缩事件」开关** — 设置页新增 showEvents（缺省开启），统一管理压缩切割通知与原文召回（spine_recall）工具行的显示，关闭则两者都隐藏（含历史记录）；纯渲染层开关，不影响压缩行为本身。设置格随主闸隐藏，取值保留、重新开启后原样恢复。
- **记忆模块优化** — 记忆检索、条目元数据与只读审计优化，跨会话知识维护更稳。
- **更新源指向 fork 与国内代理回退** — 项目地址与更新检测指向 fork 仓库；更新检测与下载支持国内代理回退。

## 优化

- **Chat 彻底退役** — 移除问答工具链、Chat 前端与后端存储链，通用组件迁移复用；用户文档同步更新。
- **流式尾块与跟随稳定化** — 未定型的流式尾块先按纯文本渲染，避免已上屏行中途重新断行；自动滚动改由应用层跟随状态判定，脱离后可恢复；补齐数学块闭合与滚轮归属判定，脱离跟随时解除库武装。
- **Live Compact 胶层护栏** — 借鉴 MerkyorLynn 0.1.4 四项护栏；Spine 卡片改落 toolResult 角色并拦截模型模仿卡片输出。
- **NSIS 产物文件名与 latest.yml 对齐** — 安装包文件名与更新清单一致，避免更新下载 404。

## 修复

- **执行过程容器自动跟随** — 修复点击/向下滚到底误脱离、小幅上滚被拽回的问题：跟随判定改用外层纯函数，follow/detached 两态加滞回与用户驱动窗口，移除内层 rAF 平滑动画改即时到底。
- **MCP OAuth 授权链路** — 集成目录 OAuth 条目（如 GitHub）缺 Client Secret 时无法完成授权的问题修复：缺密钥先弹安全输入框，保存后继续授权；token 交换原样透出提供方原始错误（此前笼统报「缺少 access_token」，掩盖凭据错配等原因），密钥框展示当前配置 clientId 供核对，避免新 App 密钥配旧 clientId。
