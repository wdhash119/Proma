# Proma v0.19.164 更新

## 修复

- **压缩事件现在会持久化并在历史里可见** — Live Compact 的切割事件（`spine_cut`）此前只存在于实时流，刷新或重开会话后消失，「显示压缩事件」开关对历史记录始终没有效果。现在切割事件随会话转录保存，重新打开会话仍可复盘上下文在哪一轮被改写。
- **切割事件进入执行过程信息流** — 切割事件不再作为独立通知行另起一块，而是与工具调用同级、按发生顺序落在所属回答的执行过程里（折叠时以剪刀图标和「N 次压缩」计入摘要）。`spine_recall`（原文召回）在开关开启时照常显示为普通工具行。
