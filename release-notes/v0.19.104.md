# Proma v0.19.104 更新

## 新增

- **千问AI平台渠道** — 新增「千问AI平台 API」与「千问AI平台 Token Plan」两个渠道入口，表单内可切换 OpenAI 兼容 / Anthropic 协议，默认端点与预设模型开箱即用；Anthropic 端点未开放模型列表，连接测试改用极小 messages 请求验证。qwen4-max 系列按 1M 上下文注册，Token Plan 自动省略不支持的 thinking 字段。旧通义千问 / DashScope 渠道保留不动。
- **人设管理** — 设置「提示词管理」升级为「人设管理」：人设库支持名称 / 说明 / 正文 / 示范对话编辑、设为默认、Markdown 导入导出，内置 4 个中性人设；旧自定义提示词一次性自动迁移，内容不丢失。Agent 输入栏新增人设选择（会话级、下一轮生效、分叉继承），正文以独立段落注入系统提示词，不覆盖工具与安全契约；侧栏问答同步改用人设。「Proma 默认助手」不注入额外提示词，编辑区展示 Proma 默认系统提示词的只读预览。
- **用户全局 Skills** — `~/.AGENTS/skills/` 下的 Skill 跨工作区生效，MCP/Skills 窗口以「全局」徽章列出并支持开关；开关写入 Proma 配置的全局禁用名单，用户目录始终只读，删除 / 更新等破坏性操作对全局 Skill 明确拒绝。

## 优化

- **侧边栏布局** — 移除头部「Agent」模式标签（Agent 已是唯一主入口），折叠按钮并入「新建任务 / 搜索」操作行；最小宽度提升至 260px，「新建任务」文字不再折行压缩，窄宽度自动隐藏内联快捷键帽（悬停提示保留）。
- **工具调用日志** — 界面宽度足够时完整显示命令、路径与参数，不再按固定比例或字符数提前截断成 …；仅真正溢出时省略。
- **Chat 退役收尾** — 清理已退役 Chat 主模式的残留代码与「Agent 模式」过时文案；问答对话交给 Agent 的动作统一称「交给 Agent 继续」。

## 变更

- **移除设置「历史 Chat」页** — 历史对话数据仍完整保留在本地（`~/.proma/conversations.json` 与 JSONL），侧栏问答与「交给 Agent 继续」不受影响；设置页不再提供历史 Chat 检索入口。

## 修复

- **协作等待不再误报失败** — `wait_for_delegations` 长等待此前会被 120 秒跨进程超时中断并显示「失败」；现在等待上限按工具自身超时参数推导，仅当子会话异常结束（失败 / 取消 / 中断）时才标记失败，等待超时返回正常的进行中状态。
- **Windows 终端叠影** — 修复控制台文字重叠、`clear` 后残留旧行的问题：xterm 改用真实 Windows build 选择 ConPTY 现代重绘路径，关闭与 ConPTY 冲突的换行转换，回放缓冲截断对齐行首，避免半个控制序列污染屏幕。
