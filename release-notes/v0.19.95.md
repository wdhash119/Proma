# Proma v0.19.95 更新

## 修复

- **项目指令激活不再阻断工具调用** — 在含 `AGENTS.md` / 旧 `CLAUDE.md` 的项目子目录里读写文件时，不再弹出「正在激活指令…请重试」并反复打断（该问题在 Pi 运行时升级后会出现同轮重试死循环）。现在首次及后续工具调用都直接成功，项目规则改为在后台透明加载、于本轮结束后无缝生效，仍只作用于对应子树、不覆盖系统安全与权限边界。
- **legacy CLAUDE.md 迁移改为非阻断** — 仅有 `CLAUDE.md` 的目录里编辑/写入不再被强制阻断；「先创建同目录 `AGENTS.md`、保留原 `CLAUDE.md`」的迁移建议以非阻断提示给出，本次修改正常放行。
