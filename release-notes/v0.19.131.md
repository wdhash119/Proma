# Proma v0.19.131 更新

## 新增

- **Live Compact** — 长对话可在本地把已完成的段落就地压缩为带来源的提取式卡片，减少上下文占用；压缩过程不调用额外模型，被切掉的原文可由 `spine_recall` 按卡片引用取回。设置 → Live Compact 提供缺省关闭的全局主闸，对话输入工具栏可为每个会话单独开关；全局关闭会停止所有会话的上下文改写，触发线、保留轮预算与紧急线随当前模型的上下文窗口自动换算。
- **Live Compact 上游同步与回退** — 设置页可检查并同步上游算法。下载内容必须通过版本号、必需导出和上游算法测试三重校验才会激活；失败时继续使用当前版本。已同步算法只作用于之后启动的会话，可随时回退到随 App 发布、始终可用的内置版本。

## 优化

- **代码精简与防回流** — 清理 19 个死代码文件、23 张未使用资产与 17 个依赖声明，退役 39 个无效 IPC channel、35 个 preload bridge 和 27 个死 atom，收紧约 690 处不必要的 export；TypeScript 开启 `noUnusedLocals` / `noUnusedParameters`，降低冗余重新累积的风险。
- **测试隔离** — 修复 Pi SDK 全局 mock 跨测试文件泄漏导致的模型能力覆盖测试失败，测试改用本地 fake sdk 注入，避免执行顺序影响结果。

## 变更

- **退役旧版 Scratch Pad 数据迁移链** — 移除旧 `loadScratchPad`、配置目录迁移及对应 IPC / preload 接线；本变更只退役迁移代码，不删除磁盘上的用户数据。

## 修复

- **退出时释放变更请求轮询器** — 应用退出现在会停止 PR 变更请求轮询、取消待处理发现任务并清理缓存，避免退出路径遗留后台工作。
