# Proma v0.19.114 更新

## 新增

- **独立余额 / 订阅额度徽标** — 余额与订阅额度从上下文圆圈的浮窗中剥离，作为独立徽标显示在输入工具栏，跟随当前选中模型所属渠道自动切换并每分钟刷新。支持「5H / 周」窗口额度、金额与积分等紧凑格式，以及供应商提供的重置时间；所有内置付费 / 订阅渠道均有加载、失败与不可用状态，不再静默隐藏。已接入查询的 DeepSeek、Kimi Coding、MiniMax、智谱、ChatGPT Codex 与 GitHub Copilot 展示真实余额，未接入可靠接口的渠道明确显示不可用原因，不伪造数字。上下文浮窗只保留 token 用量与手动压缩。

## 修复

- **对话启动时报对象无法克隆** — 项目指令状态回调此前被直接放入主进程到 Agent runtime 的 MessagePort 数据，函数无法结构化克隆，导致每次对话在调用模型前即报 `An object could not be cloned.`。回调现改经既有 query callback 通道回传，项目指令状态持久化与跨进程边界回归测试均已覆盖。
- **模型手动上下文长度被推断值覆盖** — 为 Qwen3.8 等模型手动设置较小的上下文长度后，界面仍可能按模型名推断显示 1M。现在运行时确定值（包含手动覆盖）优先于 assistant / result 的模型名推断，可向上或向下校正，后续推断事件不会再次放大；未手动覆盖时保留原有模型推断兜底。
