# Proma v0.19.140 更新

## 新增

- **Live Compact 阈值自定义与原算法档** — 设置 → Live Compact 新增「阈值设置」：起切 / 保留 / 紧急 / 停手四条线支持自定义比例（百分数输入，按当前模型上下文窗口换算）或绝对 token；新增「原算法」档只读复现上游 dsh-live-compact 原值（20000 / 32000 / 48000 / 650000）。自定义模式双输入列并排，非生效列按「参考上下文长度」实时显示换算预览；顺序校验与取整和主进程一致，非法组合就地报错并禁止保存。
- **结束轮保护开关** — Live Compact 独立开关（缺省开启）：刚结束的这一轮（末条消息与其工具结果）与投影尾部永不被切；关闭则回到上游行为，供复现上游或排查压缩效果时使用。
- **千问 Token Plan 额度显示** — 千问 Token Plan 渠道展示个人版当月剩余额度百分比与重置日期，便于掌握用量。
- **视觉中继三档模式** — 视觉助手中继新增 off / auto / force 三档：auto 仅在当前模型不支持图片输入时注入 VisionRelay 工具；force 在此基础上接管 Read 的图片结果，始终经配置的视觉模型中继。两开启档均要求中继路由完整，且无人值守来源（定时任务、协作子 Agent）一律不外发图片。

## 优化

- **Live Compact 设置页重构** — 改为开关行、双列阈值卡、算法更新三段式布局，左右列同类行严格对齐；大段分节说明收进问号 tooltip（悬停或 Tab 聚焦查看）；总开关关闭时隐藏结束轮保护与阈值设置，原算法档生效时隐藏比例/绝对值子切换并改单列只读。设置保存改为部分更新：保存任一区块不再回传页面加载时的其它字段，不会用旧值覆盖其它窗口刚改过的开关。
- **测试与回归守卫** — 仓库根 `bun test` 经 preload 统一清理宿主环境携带的 SPINE_* 覆盖（算法层在模块加载时把 env 求值成常量，曾导致污染环境下的假失败）；新增 clamp 边界漂移、dev 启动资源顺序与启动页竞态的源码钉扎回归守卫。

## 修复

- **Live Compact 切到刚结束轮** — turn_end 增加守卫：候选触及刚结束轮或投影尾部即停止后续切段，修复长输出收尾处任务被静默截断的问题；缺省开启，可在设置开关关闭。
- **新 worktree 的 dev 启动循环** — build:resources 先创建 dist 再复制资源（Bun shell 的 cp 只接受 -R，旧脚本静默吞错导致资源从未进 dist）；启动页加载失败不再销毁当时唯一窗口（非 macOS 会触发 window-all-closed 提前退出、electronmon 陷入重启循环），并补齐两处隐藏启动页残留的泄漏洞。
