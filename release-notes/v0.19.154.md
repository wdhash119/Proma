# Proma v0.19.154 更新

## 新增

- **选区提问改为右侧临时 Agent** — 在 Diff 视图、文件预览和 Obsidian 笔记中选中文本后点「打开临时 Agent」，会在右侧工作区启动一个与本会话并行的临时 Agent，选中片段以引用 chip 进入它的输入框，可继续补充问题后直接发送。同一主会话的连续选区追问复用当前打开的临时 Agent；关闭 Tab 后再次发起才会新建会话。它不继承主会话历史，需要带上分叉点之前全部对话时改用「探索此分支」。

## 移除

- **Chat 主入口与侧栏「问答」** — 侧栏不再提供 Chat / Agent 模式切换，旧 Chat 标签页、会话列表入口与设置页的历史 Chat 检索一并下线；侧栏「问答」面板同步移除，短问答改由 Agent 会话、协作子 Agent 或 MCP 服务承担。
- **Chat 工具链** — Chat 专属的对话服务、历史会话存储、文档解析、工具注册表与执行器、HTTP 工具运行时随主入口删除，相关 IPC 通道、preload 接口与共享类型不再保留。
- **tool-builder 默认 Skill** — 它只服务于侧栏「问答」里的自定义 HTTP 工具，向问答下线的流程一并退役；需要调用外部服务时改用 MCP 服务或直接 HTTP 请求。

## 保留

- **共享能力继续可用** — Markdown 渲染（含流式尾块处理）、模型选择器与渠道额度徽标、本机图片与附件读取都迁到共享位置，继续为 Agent 服务，功能没有缩减。

## 变更

- **历史 Chat 文件不再由应用读取或管理** — 应用不再读写、迁移或清理既往的 Chat 对话与附件；升级本身不会删除磁盘上的任何数据，需要留存的旧文件请自行备份。本轮本地维护中对历史 Chat 数据的物理删除是一次性、经用户明确授权的操作，不属于应用升级行为。
